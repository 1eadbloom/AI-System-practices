## 背景說明

CryptoTracker v1.0 已成功建立一套穩固的 CLI 查詢基礎——從即時價格、收藏管理到歷史紀錄匯出，整體架構層次清晰，Lazy Import 的設計也讓工具在各種環境下保持良好的啟動穩定性。

然而，在內部試用與使用者訪談後，我們收到幾項一致的反饋：

1. **收藏清單缺乏主動通知能力**：使用者必須手動執行 `favorite list` 才能得知價格變化，若持倉的幣種在深夜出現劇烈波動，完全無從得知。
2. **趨勢分析過於單一**：目前 `trend` 指令只提供移動平均線，但不同使用者對「趨勢」的定義不同，部分進階使用者希望看到更多維度的判斷依據。
3. **多幣種比較操作繁瑣**：想同時比較三、四個幣種的近期表現，目前只能逐一下指令，缺乏一次性的橫向比較視角。
4. **設定檔形同虛設**：`config.json` 雖已預留，但完全未啟用，導致每次查詢都要重複輸入 `--currency twd` 這類個人偏好參數。

基於以上回饋，v2.0 的核心目標是在不破壞現有架構的前提下，讓 CryptoTracker **從被動查詢工具演進為具備主動感知能力的個人投資追蹤助手**。

## 需求列表

### 需求一｜啟用個人設定檔（修改既有模組）

目前 `~/.cryptotracker/config.json` 已存在但內容未被任何模組讀取。我們希望正式啟用這個設定檔，讓使用者可以儲存個人偏好，使其在每次執行指令時自動生效，無需重複輸入。

預期可設定的偏好項目至少包含：

- **預設法幣**（如 `twd`、`jpy`），影響 `price`、`favorite list` 等所有涉及價格顯示的指令
- **預設顯示筆數**，影響 `top` 指令的預設 `--num` 值
- 其他你認為合理的個人偏好參數

此外，應提供一個新的 `config` 子指令，讓使用者可透過 CLI 直接讀取與修改設定，而非要求使用者手動編輯 JSON 檔案。設定的優先順序應為：**指令列參數 > 設定檔 > 程式內建預設值**。

> 💡 **設計提示**：這項需求會同時觸及 `storage.py`（讀寫 config）、`commands.py`（套用設定）以及 `main.py`（新增 config 子指令）三個模組，請思考如何讓設定的載入時機與現有的 Lazy Import 架構相容。

---

### 需求二｜價格警示功能（全新功能）

使用者希望能為收藏清單中的幣種設定價格警示條件，當執行任何查詢指令時，若即時價格觸發條件，系統應在正常輸出之外額外顯示醒目的警示訊息。

警示條件應至少支援：

- 價格**高於**某個閾值時觸發（例如：bitcoin 超過 100,000 USD）
- 價格**低於**某個閾值時觸發（例如：ethereum 跌破 2,000 USD）

警示的管理應透過新的 `alert` 系列子指令操作，包含新增、移除與列出現有警示。警示紀錄的儲存方式與位置由你自行決定，但應與現有儲存架構保持一致性。

觸發警示時的顯示方式應讓使用者一眼就能注意到，具體呈現方式不限。

> 💡 **設計提示**：警示的「檢查時機」是一個值得思考的設計問題——是每次執行任何指令都檢查，還是只有特定指令才檢查？不同的選擇會影響使用者體驗與程式結構，請在設計文件中說明你的決策理由。

---

### 需求三｜多幣種比較指令（全新功能）

新增一個 `compare` 指令，允許使用者一次輸入多個幣種，並以**對齊的表格格式**並排顯示其關鍵資訊，方便橫向比較。

顯示的欄位應至少包含：

- 幣種名稱
- 即時價格（依使用者設定的預設法幣顯示）
- 指定天數內的**價格漲跌幅**（百分比）

指令設計範例（介面細節可自行調整）：

```
python main.py compare --coins bitcoin ethereum solana --days 7
```

比較的幣種數量不應有硬性上限，但需考量 API 呼叫效率，避免對 CoinGecko Free API 造成不必要的請求壓力。

> 💡 **設計提示**：漲跌幅的計算需要歷史價格資料，`crypto_api.py` 中應已有相關的 API 呼叫邏輯可供參考或複用。表格的對齊格式請思考如何處理幣種名稱長度不一的情況。

---

### 需求四｜強化趨勢分析（修改既有模組）

現有的 `trend` 指令僅輸出移動平均線數值，使用者反映「看不出來到底要告訴我什麼」。我們希望強化這個指令的輸出，使其更具可讀性與參考價值。

具體要求：

- 在原有移動平均線的基礎上，**額外提供至少一種新的分析維度**（例如：波動率、價格區間、或短期與長期均線的相對位置關係——確切選擇由你決定）
- 在數字輸出之外，提供一段**文字摘要**，以自然語言描述當前趨勢狀態（例如：「近 30 天呈現震盪整理，短期均線位於長期均線下方」），讓不熟悉技術分析的使用者也能快速理解

文字摘要的判斷邏輯應封裝在 `utils.py` 中，並且邏輯本身需可單獨被測試，不應與輸出格式耦合。

## 驗收標準

以下以使用者可直接觀察的行為描述驗收條件：

1. **設定檔生效**：使用者執行 `python main.py config set --currency twd` 後，再執行 `python main.py price --coin bitcoin`，應直接顯示台幣價格，無需再加 `--currency twd` 參數；執行 `python main.py config get` 應能看到目前所有設定值。

2. **價格警示觸發**：使用者為 bitcoin 設定低於某價格的警示後，執行 `python main.py favorite list` 時，若 bitcoin 當前價格低於該閾值，輸出中應出現與一般資訊明顯區隔的警示文字，且正常的收藏清單內容仍應完整顯示。

3. **多幣種比較呈現**：執行 `compare` 指令並輸入三個以上幣種時，輸出應以對齊的多欄表格呈現，每個幣種各佔一列，欄位標題清晰可辨，漲跌幅以百分比顯示且正負號明確。

4. **趨勢分析可讀性**：執行 `trend` 指令後，輸出的最後應有一段純文字摘要，即使使用者完全不理解移動平均線，也能從該段文字判斷「這個幣種近期走勢是向上、向下還是盤整」。

5. **向下相容性**：v1.0 的所有既有指令（`price`、`top`、`history`、`export`、`favorite` 系列）在未修改任何設定的情況下，行為應與 v1.0 完全一致。
