## 評語（兩個模型獨立評分，僅供回饋）

### Claude Opus 4.8
B Benchmark分析 88：REPORT 正確列出純 BM25 接不到的 4 題，並分門別類為 vocabulary mismatch、distractor 稀釋、跨語言 lexical 天花板等成因，分析具體且與實測 Recall@5=0.810/MRR=0.810/nDCG=0.802 完全吻合。中文查詢對英文記憶的跨語言天花板分析尤其到位。小扣分在於部分題目以「可能／若」推測記憶內容，未直接核對語料實際 term，略缺確證。
C 進階設計 80：任務二採 BM25+embedding 的 RRF 融合，保留純 bm25_search() 不動（題目硬性要求達成），並具備離線快取、本地路徑與自動 fallback 至 BM25 的穩健設計，trade-off（小語料 lexical 友善、alpha=0.5 非最佳、MRR/nDCG 微降）說明清楚。harness 實測 hybrid delta=0.0（等同 BM25，未重現改進），依規定不扣分，僅就設計品質評分；可再補上大語料的實際改進數據以強化論證。
D 反思/可重現 84：七問皆有作答且品質佳：gaming 以語料/查詢分離與確定性演算法論證不可作弊；確定/機率分界以表格清楚劃分並提出『確定性外殼包機率核心』；token 預算貪心填入與 context window 比例取捨合理；/compact（session 內）vs 跨 session 持久記憶、與手寫 PROGRESS.md 比較均到位。環境記錄完整，README 含 pip/pytest/benchmark 與離線三方案，可重現性高。Windows path 註記真實但略凌亂。

### ChatGPT gpt-5.5
B Benchmark分析 88：BM25 小語料數字與實測一致，列出 4 題未命中並以詞彙不匹配、跨語言與 distractor 稀釋解釋，方向正確但部分仍以推測語氣描述。
C 進階設計 82：Hybrid 設計保留純 BM25，具 embedding、RRF、離線與 fallback 說明，trade-off 清楚；但實測大語料未改善，且每次重算 embedding 與融合參數仍可優化。
D 反思/可重現 90：七項反思大致完整，涵蓋可驗證性、確定與機率分界、token 預算、/compact、PROGRESS.md 與環境；README 可重現核心流程，hybrid 依賴模型快取。
